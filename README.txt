مرجع المرحلة الثانية — نسخة المزامنة المركزية

هذه النسخة تجعل بيانات الموقع مشتركة بين الهاتف واللابتوب باستخدام Netlify Function + Netlify Blobs.

مهم جداً:
هذه النسخة تحتاج نشر Netlify يدعم Functions. النشر بالسحب والإفلات كملفات ثابتة فقط قد لا يفعّل الـ Functions.
استخدم Git/Deploy من مستودع أو Netlify CLI للنشر الكامل.

بعد النشر:
1) افتح الموقع.
2) ادخل للأدمن من الهاتف.
3) انشر تبليغاً أو عدّل محاضرة واضغط حفظ.
4) افتح الموقع من اللابتوب؛ يجب أن تظهر نفس البيانات.

الواجهة والتصميم محفوظان، والتعديل الأساسي هو المزامنة المركزية ومنع نسخ جدول الأسبوع الأول تلقائياً إلى بقية الأسابيع.
